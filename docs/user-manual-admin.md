# Administrator guide

1. Sign in with an account assigned the Admin role. Use the Dashboard for operational KPIs and analytics.
2. In **Admin Panel**, review Reports and Requests, set priority, assign personnel, and verify completed work. Provide a reason when returning work for rework.
3. Configure priority target times in **SLA Settings**. Deadlines are computed when priority is set or changed.
4. Use **Locations & Maintenance** to manage facility locations, print QR sheets, and create, pause, edit, or generate preventive-maintenance schedules.
5. Use **Activity Log** to inspect the append-only audit trail and **User Management** to manage approved accounts and roles.
6. Open **Evaluation Results** for anonymous SUS and ISO/IEC 25010 summaries and export the aggregated results as CSV.
7. Use the job-order print action on a service request to print or save a PDF.

Apply database migrations before enabling production workflows. Never share an account or service-role key. Review the [deployment guide](../DEPLOYMENT.md) for production setup and the optional demo seed procedure.
