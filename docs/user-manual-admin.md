# Administrator guide

1. Sign in with an account assigned the Admin role. Use the Dashboard for operational KPIs and analytics.
2. In **Admin Panel**, review Reports and Requests, assign personnel, and verify completed work. Provide a reason when returning work for rework.
3. Use **Locations & Maintenance** to manage facility locations, print QR sheets, and create, pause, edit, or generate preventive-maintenance schedules.
4. Use **Activity Log** to review request and sign-in history. In **User Management → Pending Approvals**, review new account requests, assign the correct role, then approve or reject them. Approved users can sign in after any required email confirmation. Use **University Users** to manage active accounts and roles.
5. Open **Evaluation Results** for anonymous SUS and ISO/IEC 25010 summaries and export the aggregated results as CSV.
6. Use the job-order print action on a service request to print or save a PDF.

Apply database migrations before enabling production workflows. Never share an account or service-role key. Review the [deployment guide](../DEPLOYMENT.md) for production setup and the optional demo seed procedure.
