# Maintenance personnel guide

1. Sign in and open **Tasks** to view work assigned to your account.
2. Open a task to review its location, description, priority, deadline, and any before photos.
3. Accept the assignment and mark it **In progress** when work starts.
4. When the repair is ready for review, mark it complete and optionally add after photos. Its status moves to **For verification**; the Admin or Assistant completes the verification.
5. If a task is returned for rework, review the reason, carry out the additional work, and submit it for verification again.
6. Use **System Evaluation** to optionally submit an anonymous survey.

Personnel can only view assigned work and may update workflow/completion fields for those assigned items; assignment, requester identity, priority, and other protected fields remain administrator-controlled.
