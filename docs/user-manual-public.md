# Public reporter guide

1. Open the UNIFIX home page and choose **Submit a Report**.
2. Enter a short title, a clear description, the issue category, and the campus location. Add an email only if you want status updates.
3. Optionally attach up to three JPG, PNG, or WebP photos. The browser compresses the images before upload.
4. Complete Cloudflare security verification and submit. Keep the tracking code shown on the confirmation.
5. Use **Track a Report** and enter the tracking code to see the progress timeline. The public tracking page does not show personal details or internal notes.
6. If offline, submit the draft to save it in this browser. Reconnect, restore the draft, complete security verification, and submit it.
7. After completion, use the feedback prompt on the tracking page if available. Feedback is optional and can be submitted once per report.

Do not share a tracking code publicly; it is used to access the report's limited status information.
